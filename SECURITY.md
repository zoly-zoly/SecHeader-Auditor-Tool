# Security Policy

## Supported Versions

We take the security of **SecHeader-Auditor** seriously. Security updates and patches are provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or a bug within **SecHeader-Auditor**, please **do not open a public GitHub issue**. Public disclosures can put users at risk before a patch is released.

Instead, please report it via one of the following methods:

1. **Direct Email:** Send an email detailing the vulnerability to the project maintainer.
2. **Private Advisory:** Use GitHub's private vulnerability reporting feature on the repository's Security tab.

### What to Include in Your Report:
- A clear description of the vulnerability and potential impact.
- Step-by-step instructions, scripts, or proof-of-concept (PoC) to reproduce the issue.
- Any suggested remediations or patches (if applicable).

### Response Timeline:
- **Acknowledgment:** We aim to acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment:** We will investigate, verify the issue, and evaluate its severity.
- **Remediation & Disclosure:** Once a patch is developed and verified, we will coordinate a public disclosure and release a security advisory.

Thank you for helping keep SecHeader-Auditor and its community secure!
